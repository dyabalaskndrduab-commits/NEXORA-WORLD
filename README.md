# NEXORA WORLD

Android-first 2.5D social virtual-world project built with Kotlin, OpenGL ES and a Node.js/Socket.IO backend.

## Current backend milestone: 0.5.1 — PostgreSQL account persistence

The Android client contains a playable 140 × 140 city district with touch movement, a generated GLB avatar, orbit camera, roads, plaza, towers, retail buildings, parks, landmarks and building collision. The social client includes account registration/login, encrypted token storage, Socket.IO authentication, remote player rendering, room creation/join/leave, public-room listing and room chat.

The backend owns player identity, room membership, invite codes, movement validation and room-scoped chat. This milestone adds a PostgreSQL account store and a versioned database migration. Production mode refuses to start with in-memory accounts. The Android app remains version 0.5.0; this backend-only update does not produce a new Android APK.

**Important scope boundary:** only account records are persisted in 0.5.1. Active player presence, private-room membership/invite codes and chat history remain transient and are cleared when the server process stops. The project is not yet a production-ready live service.

## Android build

- Android Gradle Plugin 8.7.3
- JDK 17
- Gradle 8.9
- Build locally with \`gradle testDebugUnitTest assembleDebug\`.
- GitHub Actions generates the character GLB, runs backend and Android tests, builds the debug APK and packages the source project.

## Character asset

The Android scene loads \`app/src/main/assets/NEXORA_Character_v1.glb\`, generated by \`tools/build_nexora_avatar.py\`; named mesh parts are animated by the Android renderer. The separately supplied static GLB still needs an import/texture pass before it can replace this character. No skeletal rig or animation clips are claimed for that separate model.

## Social backend

See \`backend/README.md\` and \`backend/.env.example\`.

- Local development without \`DATABASE_URL\` uses temporary in-memory accounts.
- Production requires \`DATABASE_URL\`, \`DATABASE_SSL=require\`, a strong \`JWT_SECRET\`, and the \`nexora_accounts\` migration.
- Run \`cd backend && npm install && npm test\` for unit tests.
- With PostgreSQL available, run \`npm run migrate && npm run test:integration\` to verify an account survives a backend process restart.

No production backend URL or database credentials are committed to this repository. Physical phones need a reachable HTTPS backend URL; \`10.0.2.2\` is only the Android emulator's host-machine alias.
