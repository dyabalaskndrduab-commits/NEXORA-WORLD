# NEXORA WORLD

Android-first 3D social-world foundation, built with Kotlin and OpenGL ES 2.0.

## Current milestone: 0.5.0 — Server-authoritative room foundation

The Android client currently provides a local, playable 3D exploration build:

- Perspective 3D scene with a controllable character rendered from a generated GLB asset.
- Code-driven limb movement for the character's separate mesh parts.
- Touch joystick movement and drag-to-orbit camera controls.
- Expanded 140 × 140 city area with four main avenues and a wider outer road ring.
- Central NEXORA plaza, residential towers, retail buildings, two pocket parks, a mall landmark and a club landmark.
- Building-footprint collision checks and a bounded world area.

The game client remains a **single-player local build** until the Android app is connected to the backend.

## Backend 0.5.0

The backend now validates private-room invite codes, room capacity, host transfer, room-scoped chat and snapshots, and normalized player movement. It rate-limits authentication attempts and rejects the development JWT fallback in production. Accounts, online players, and rooms are still in memory; this is a development milestone, not a production service.

Run backend tests with:

```bash
cd backend
npm test
node --check src/server.js
```

See `backend/README.md` for the event protocol and limitations.

## Android build

- Android Studio project
- JDK 17
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Debug build: `gradle assembleDebug`

GitHub Actions generates the character GLB and builds the debug APK on pushes, pull requests, and manual runs.

## Character asset

The Android scene currently loads `app/src/main/assets/NEXORA_Character_v1.glb`, generated by `tools/build_nexora_avatar.py`. The separately supplied static GLB model still needs a dedicated import/texture-compatibility pass before it can replace this in-game character. No skeletal rig or animation clips are claimed for that separate model.
